# instructorhamid.github.io

Personal website of Hamid (@instructorhamid), Digital Marketing & Marketing Automation Strategist.

Live at https://instructorhamid.github.io

- `index.html` — the full single-page site (styles and scripts inline)
- `assets/` — portrait, tool logos and project screenshots

The contact form has no backend: it prepares a WhatsApp message. To collect inquiries automatically, replace `sendInquiry()` in `index.html` with a POST to a GoHighLevel, n8n or Zapier webhook.
